# Resources & Further Reading

A curated set of external references that inform the methodology used throughout this repository.

## Core References

| Resource | Description |
|---|---|
| [HackTricks](https://book.hacktricks.xyz/) | Extensive pentesting methodology and technique reference |
| [PayloadsAllTheThings](https://github.com/swisskyrepo/PayloadsAllTheThings) | Payload and technique reference across many attack classes |
| [GTFOBins](https://gtfobins.github.io/) | Unix binary privilege-escalation/restriction-bypass reference |
| [OWASP](https://owasp.org/) | Web application security methodology and testing guides |
| [SecLists](https://github.com/danielmiessler/SecLists) | Wordlists for fuzzing, brute-forcing, and discovery |
